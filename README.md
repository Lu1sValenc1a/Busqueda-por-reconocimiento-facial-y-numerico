# Busqueda por reconocimiento facial y numerico
Construcción de una plataforma escalable para la venta de fotos utilizando Aws y Stripe.
El sistema utilizará servicios de AWS para almacenamiento, procesamiento y entrega, y Stripe para el procesamiento seguro de pagos. Las funcionalidades principales del proyecto están predefinidas; se requiere principalmente la personalización e integración de tecnologías existentes.
